# Edge Add-ons listing (English)

## Name
SuiYuan Search

## Short description (<=132 chars)
A clean new tab: big clock, capsule search, wallpaper library, Bing daily, multilingual UI.

## Detailed description
SuiYuan Search is a zero-build browser start page with a large clock, capsule search, bottom dock and wallpaper backgrounds.

Features:
- Big clock and date with selectable font weight, synchronized colon blinking, 12/24-hour formats
- Search with Bing, Google or Baidu, custom engines, Ctrl+1~9 shortcuts
- Aggregated search suggestions with per-query cache
- Optional search history
- Wallpaper library: built-in wallpapers, local images and video wallpapers
- Focal point picker for proportional cropping
- Bing daily wallpaper with copyright, 4K toggle, download and auto-save to library
- Dock shows up to 10 bookmarks; "..." opens a 5-7 column favorites panel
- Bookmark management: add, edit, reorder, move to top, import browser bookmarks, JSON import/export
- Languages: Auto, Simplified Chinese, Traditional Chinese, English, French, Russian, Spanish, Arabic (RTL)
- Theme: follow system / light / dark

Privacy:
- No data is collected or uploaded
- Settings, bookmarks and history stay in the browser (chrome.storage in extension, localStorage on the web)
- Images and videos stay in local IndexedDB
- Network requests are limited to Bing/Baidu/Google suggestions and Bing wallpaper APIs
