# 2.1.0 更新记录（各语言）

## 简体中文 (zh_CN)
2.1.0 更新
- 新增三张默认壁纸和默认视频背景
- 壁纸库支持多图/多视频上传、缩放中心，必应壁纸下载后自动入库
- Dock 最多显示 10 个网站，溢出时按整图标收纳；「…」展开 5~7 列、5 行的收藏面板
- 收藏夹支持置顶、清空、导入浏览器收藏夹（只读）
- 新增 7 种界面语言，支持阿拉伯语 RTL
- 时钟支持字重选择、冒号同步闪烁、12 小时制 0/12 点规则
- 修复缩放中心二次保存、搜索历史开关、联想残留、视频切图片不显示等问题

## 繁體中文 (zh_TW)
2.1.0 更新
- 新增三張預設桌布和預設影片背景
- 桌布庫支援多圖/多影片上傳、縮放中心，Bing 桌布下載後自動加入
- Dock 最多顯示 10 個網站，溢出時按整圖示收納；「…」展開 5~7 欄、5 列的收藏面板
- 書籤支援置頂、清空、匯入瀏覽器書籤（唯讀）
- 新增 7 種介面語言，支援阿拉伯語 RTL
- 時鐘支援字重選擇、冒號同步閃爍、12 小時制 0/12 點規則
- 修正縮放中心二次儲存、搜尋紀錄開關、聯想殘留、影片切換圖片不顯示等問題

## English (en)
2.1.0
- New default wallpapers and a default video background
- Wallpaper library with multi-image/video upload, focal point picker, and Bing downloads saved to the library
- Dock shows up to 10 sites; overflow is collapsed by whole icons and "..." opens a 5-7 column, 5-row panel
- Bookmarks: move to top, clear all, import browser bookmarks (read-only)
- Seven interface languages, including Arabic RTL
- Clock font weight, synchronized colon blinking, and 12-hour 0/12 rules
- Fixed focal point re-saving, history toggle, stale suggestions and video-to-image switching
